# Malik Oil Expellers Online Store

Production-ready React/Vite storefront for Malik Oil Expellers, with Firebase Firestore data sync, customer ordering, inventory management, and admin authentication.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run lint
npm run build
```

The generated `dist` folder can be deployed to Vercel or any static hosting provider. Firebase Firestore and Authentication must be enabled for cloud data and admin login.
